# Триаж независимых замечаний

- **Critical** — воспроизводимая утечка секретов, разрушение пользовательских файлов, выход из scope с необратимыми последствиями.
- **High** — нарушение опубликованного CLI/JSON контракта, безопасности файлового обхода, воспроизводимое неверное поведение главной capability.
- **Medium** — ошибка обработки граничного случая, регрессия настроек/диагностики, значимый пробел обязательного теста, ошибочная архитектурная зависимость.
- **Low** — предметная локальная проблема сопровождения с измеримым эффектом. Косметические пожелания не findings.

Каждый вывод подкрепляй кодом, местом вызова, тестами и условиями проявления; указывай строки текущего проверяемого SHA. Не называй дефектом любую строковую или числовую константу: докажи наличие общего источника истины, логическую ошибку или нарушение конфигурации. Не требуй формального выделения абстракции, если код не дублируется.

Особый контроль для Language Review: `scan` не исправляет язык; `config show` скрывает похожие на секреты данные в URL и параметрах запроса; обработка символических ссылок не выходит за корень; `doctor` может сообщить о недоступной внешней программе, но `scan` остаётся независимым; `uv.lock` фиксирует зависимости и не редактируется вручную. Не выдавай тесты в Ubuntu за приемочную проверку Windows.
