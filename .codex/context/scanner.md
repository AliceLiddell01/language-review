# Контракт инвентаризации

`scan` — детерминированная инвентаризация, а не поиск языковых ошибок. Канонические значения и схема определены в `scanner.py`, `report.py` и тестах.

- Сохраняй учёт входных файлов/каталогов, настроенных расширений, glob-исключений и `.gitignore`, включая исключающие правила.
- Сохраняй защиту от циклов и выхода за заданный корень при `--follow-symlinks`, корректный учёт BOM/кодировки, бинарных файлов, размера, новых строк, чтения и причин `selected/skipped/error`.
- Вывод JSON не содержит текстовых ошибок, если анализатор не реализован. `schema_version`, `files`, `summary`, семантика stderr/stdout и коды завершения являются контрактом.
- Внутренний `_source_sha256` используется только `extract` для проверки неизменности исходника между обходом и чтением. `report.py` исключает это поле из публичного JSON `scan`.
- Не изменяй исходники и не обходи игнорируемые пользовательские пути через служебные проверки.
- При изменении `scan` покрывай положительные и отрицательные сценарии, Unicode, граничные случаи с каталогами, символическими ссылками, правами, исключениями и детерминированностью. Тест должен обращаться к настоящему `scan`, а не локальной переписанной версии алгоритма.
