# Проверка реального Language Review

1. Запусти `uv sync --locked`, статические проверки и модульные тесты согласно `.codex/context/verification.md` — документу с каноническим перечнем проверок Windows.
2. Запусти `scripts/verify-package.ps1` в Windows PowerShell; скрипт должен собрать wheel и sdist, установить их отдельно и вызвать *установленный* CLI, а не импортировать исходники через `PYTHONPATH`.
3. Подготовь синтетические входы `.rs`, `.cs`, `.cpp`, `.md` и случаи с BOM, CRLF, Unicode, смешанной кодировкой, двоичным содержимым, превышением размера, игнорируемыми и недоступными файлами, символическими ссылками и циклами (если это позволяет ОС).
4. Для `scan` сравни JSON и статус с текущим публичным контрактом; проверь, что исходные файлы не изменились и ошибки не вызвали побочных эффектов.
5. Для `config show` проверь приоритет параметров и маскирование токенов; для `doctor` — доступные и недоступные явно заданные локальные сервисы. Не обращайся к внешней сети без необходимости.
6. Проверь Ctrl-C и коды завершения только в изолированной среде, без риска прервать пользовательскую сессию.
7. Удали созданные временные данные, не удаляя чужие файлы. Верни таблицу результатов и укажи пропущенные платформы.
