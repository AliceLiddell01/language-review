# Правила проекта Language Review

- Проект независим от AzurPilotRu и принимает пути к любым репозиториям.
- Команды разработки выполняются в PowerShell на Windows; рабочий runtime зафиксирован в .python-version.
- Инвентаризация, диагностика и просмотр конфигурации не изменяют проверяемые файлы.
- Языковой анализ не считается реализованным, пока нет настоящего анализатора.
- Зависимости фиксируются в uv.lock; lock-файл обновляется через uv, вручную не редактируется.
- Перед завершением запускай uv sync --locked, ruff check, ruff format --check, mypy, pytest -n 8 и scripts/verify-package.ps1.
