# Конфигурация и диагностика

Источники истины: `project_config.py`, `config.py`, `doctor.py`,
`tests/test_project_config.py`, `tests/test_project_routing.py`, `tests/test_config.py`.

- `scan`/`extract`/`check` требуют `.language-review.yaml` каждого корня. Ближайший
  `.git` (включая файл worktree) задаёт границу; вне Git корень — каталог цели
  или родитель файла. Вложенные репозитории обходятся только отдельными целями.
- YAML строго валидируется до движков. Профиль, `path_rules`, модели и уровни рассуждения,
  стратегии/бюджеты и prompts принадлежат проекту. `--profile` принудительный;
  разовые CLI-параметры имеют высший приоритет. TOML не подменяет языковую политику.
- Пользовательский TOML/`--config` владеют средой, endpoints, Vale program/config,
  OAuth, настройками памяти и отдельными согласиями cloud/cloud-memory. YAML не
  может выдавать полномочия. Фоновый обработчик памяти сохраняет прежние границы.
- Эффективная политика создаёт отдельный экземпляр движка/бюджет для каждого
  входного корня и одинаковых настроек; документы с одинаковой политикой делят
  соединение. Метаданные документа и подпрогона связывают модель с единицами.
- Промпты: общие → профильные overrides по ключам, `null` возвращает встроенный
  текст. Файлы только внутри корня, с ограничениями UTF-8/размера/сложности.
  Программная схема, маски, цитаты и смысловые проверки неизменяемы.
- `config show [цель]`/`validate` не запускают движки и не раскрывают промпты,
  термины, секреты или абсолютные пути. `show --environment` диагностирует прежнюю конфигурацию
  TOML. `doctor` диагностирует пользовательскую среду. `init` — отдельная явная
  запись локального шаблона без перезаписи существующего файла.
- Имя `extract.message_calls` — сегменты через `.`, `::`, `->`; дефис допустим
  внутри сегмента, `!` только в конце. Сопоставление полного имени без регистра
  и пробелов. Структурные селекторы принадлежат [extraction.md](extraction.md).

Пользовательский контракт и миграция: [project-configuration.md](../../docs/project-configuration.md).
