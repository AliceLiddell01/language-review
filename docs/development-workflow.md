# Процесс разработки и ревью

Этот документ поясняет рабочий процесс, а не повторяет `AGENTS.md` или реализации скиллов.

## Публикация

Одна задача оформляется отдельной веткой от актуального `main` и PR. Опубликованный SHA, актуальность diff и соответствие исходным требованиям проверяются перед передачей PR. Merge производится только по отдельному запросу. Не включай автоматический merge в Renovate или CodeRabbit.

## Ревью

Независимое код-ревью проверяет требования, соседний код и тесты; CodeRabbit — отдельный, **только явно запрашиваемый** цикл. Найденные провайдером замечания не принимаются автоматически: сначала исследуются исходники, места вызова, симптомы и контракт. Число итераций и порядок работы с CodeRabbit определяет [соответствующий skill](../.agents/skills/language-review-coderabbit-review/SKILL.md); режим выбирается по прямому указанию.

## CI и безопасность

CI для PR проверяет закреплённое окружение, Ruff, mypy и агентские валидаторы на Ubuntu. Полный pytest и проверка сборки пакета выполняются на Windows, где находится поддерживаемая среда выполнения; Linux pytest не является обязательным контрактом текущего продукта. Полный анализ безопасности выполняет CodeQL для Python и GitHub Actions при поддержке GitHub Code Security. Если CodeQL недоступен, отсутствие результата проверки безопасности нельзя выдавать за PASS. Полный набор команд приведён в [контексте проверок](../.codex/context/verification.md).

Обрабатываемые файлы, результаты экспериментов, учётные данные, локальные настройки и текстовые отчёты должны оставаться за пределами Git или под `.gitignore`. Перед открытой публикацией проверь историю, а не только текущую рабочую копию. Доступность CodeRabbit и Renovate зависит от подключения соответствующих GitHub Apps.
