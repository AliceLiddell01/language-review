# Триаж независимых замечаний

- **Critical** — воспроизводимая утечка секретов, разрушение пользовательских файлов, выход из scope с необратимыми последствиями.
- **High** — нарушение опубликованного CLI/JSON контракта, безопасности файлового обхода, воспроизводимое неверное поведение главной capability.
- **Medium** — ошибка обработки edge case, регрессия настроек/диагностики, значимый пробел обязательного теста, ошибочная архитектурная зависимость.
- **Low** — предметная локальная проблема сопровождения с измеримым эффектом. Косметические пожелания не findings.

Каждый вывод подкрепляй кодом, callsite, тестами и условиями проявления; цитируй строки текущего reviewed SHA. Не называй hardcode все строковые/числовые литералы: докажи наличие общего source of truth, логическую неверность или нарушение конфигурации. Не требуй формального абстрагирования того, что не дублируется.

Особый контроль для Language Review: `scan` не делает лингвистическую коррекцию; `config show` скрывает secret-like URL/query; symlink handling не выходит за корень; `doctor` может сообщить недоступность внешней программы, но `scan` остаётся независимым; `uv.lock` — lock, а не сборник ручных пинов. Не выдавай Ubuntu тесты за Windows acceptance.
